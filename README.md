# Ninja Village

A 3D village-themed action game built in Unity.

## Gameplay
- Walk (W) and Run (R) movement states
- Collect coins to increase score
- 3 lives — hit a bomb 3 times and it's Game Over
- Full menu flow: Main Menu → Help / Credits / Start Game → Game Over Menu

## What I built
- Custom player controller (movement, walk/run states)
- Camera-follow system
- Coin collection & scoring logic
- Lives/health system with bomb collision and game-over trigger
- Canvas-based UI: Main Menu, Help Menu, Credits Menu, Game Over Menu
- Environment: terrain, village buildings, carts, props

## Assets used
- Character animations: Mixamo
- Sound effects & music: Pixabay

## Tech
Unity, C#
